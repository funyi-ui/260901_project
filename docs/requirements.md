# 개인 프로필 페이지 요구사항

## 1. 개요

### 목적

방문자가 프로필 소유자의 소개, 역량, 주요 작업물과 연락 방법을 빠르게 파악하도록 합니다.

### 대상 사용자

- 채용 담당자 또는 협업 파트너
- 포트폴리오와 경력을 확인하려는 방문자
- 프로필 소유자에게 연락하려는 사용자

## 2. 페이지 구성

### 헤더와 내비게이션

- 이름 또는 개인 로고를 표시합니다.
- 소개, 기술, 프로젝트, 연락처 섹션으로 이동하는 메뉴를 제공합니다.
- 메뉴를 선택하면 해당 섹션으로 부드럽게 이동합니다.
- 모바일에서는 작은 화면에 적합한 메뉴를 사용합니다.

### 메인 소개(Hero)

- 프로필 사진 또는 대표 이미지를 표시합니다.
- 이름, 직무 또는 한 줄 소개를 강조합니다.
- 자기소개나 프로젝트 영역으로 이동하는 주요 버튼을 제공합니다.

### 자기소개(About)

- 간결한 소개문을 제공합니다.
- 관심 분야, 경력 요약 또는 목표를 표시합니다.
- 필요한 경우 이력서 다운로드 링크를 제공합니다.

### 기술(Skills)

- 보유 기술을 HTML, CSS, JavaScript 등 범주별로 표현합니다.
- 숙련도를 표시할 경우 주관적인 수치보다 사용 경험이나 활용 사례를 함께 적습니다.

### 프로젝트(Projects)

각 프로젝트 카드에는 다음 정보를 포함합니다.

- 프로젝트명과 대표 이미지
- 프로젝트 설명 및 담당 역할
- 사용 기술
- 데모와 소스 코드 링크

링크가 없는 경우 빈 링크를 만들지 않고 해당 버튼을 숨깁니다.

### 연락처(Contact)

- 이메일, GitHub, LinkedIn 등 실제 사용하는 연락 수단을 제공합니다.
- 연락 폼을 구현할 경우 이름, 이메일, 메시지를 입력받습니다.
- 정적 페이지에서는 제출 내용을 실제로 전송하지 않으므로 이메일 링크 또는 별도 폼 서비스를 사용합니다.

### 푸터

- 저작권 문구와 현재 연도를 표시합니다.
- JavaScript를 이용해 연도를 자동 갱신할 수 있습니다.

## 3. 기능 요구사항

- 내비게이션 링크를 통한 섹션 이동
- 모바일 메뉴 열기 및 닫기
- 현재 보고 있는 섹션에 해당하는 메뉴 강조
- 프로젝트 카드의 외부 링크 제공
- 연락처 링크 제공
- 선택 기능: 라이트/다크 테마 전환 및 사용자 선택 저장

## 4. 반응형 기준

- 모바일: 320px 이상
- 태블릿: 768px 이상
- 데스크톱: 1024px 이상

콘텐츠가 화면 밖으로 넘치지 않아야 하며, 작은 화면에서는 프로젝트 카드와 기술 목록을 한 열로 배치합니다.

## 5. 접근성 기준

- 문서의 기본 언어를 한국어(`lang="ko"`)로 지정합니다.
- 제목은 `h1`부터 순서에 맞게 사용합니다.
- 모든 의미 있는 이미지에 적절한 대체 텍스트를 제공합니다.
- 키보드만으로 메뉴, 버튼과 링크를 사용할 수 있어야 합니다.
- 포커스 표시를 제거하지 않습니다.
- 텍스트와 배경 사이에 충분한 명도 대비를 확보합니다.
- 아이콘만 있는 버튼에는 접근 가능한 이름을 제공합니다.
- 사용자의 애니메이션 축소 설정을 존중합니다.

## 6. 성능 및 호환성

- 최신 Chrome, Edge, Firefox, Safari에서 주요 기능이 동작해야 합니다.
- 이미지는 적절한 크기로 압축하고 가능한 경우 WebP 형식을 사용합니다.
- 화면 아래 이미지는 지연 로딩(`loading="lazy"`)을 적용합니다.
- 불필요한 라이브러리 없이 기본 HTML, CSS, JavaScript를 우선 사용합니다.

- [ ] 프로필 사진
- [ ] 보유 기술 목록
- [ ] 프로젝트별 설명, 이미지, 기술, 링크
- [ ] 이메일 및 소셜 링크
- [ ] 이력서 파일(선택)

## 8. 완료 조건

- [ ] 모든 필수 섹션이 표시된다.
- [ ] 모든 내부 및 외부 링크가 정상 동작한다.
- [ ] 모바일과 데스크톱에서 레이아웃이 깨지지 않는다.
- [ ] 브라우저 개발자 도구에 JavaScript 오류가 없다.
- [ ] 키보드로 주요 기능을 사용할 수 있다.
- [ ] 이미지 대체 텍스트와 폼 레이블이 제공된다.
- [ ] 실제 개인정보와 링크를 배포 전에 다시 확인한다.
