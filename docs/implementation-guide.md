# 구현 가이드

## 1. 기술 범위

- HTML5: 문서 구조와 콘텐츠
- CSS3: 레이아웃, 반응형 디자인, 색상 및 애니메이션
- JavaScript: 모바일 메뉴, 섹션 강조, 테마 등 사용자 상호작용

초기 버전은 별도의 프레임워크나 빌드 도구 없이 구현합니다.

## 2. 파일 구조

```text
frontend/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    │   ├── profile.webp
    │   └── projects/
    └── icons/
```

## 3. HTML 작성 기준

- `header`, `nav`, `main`, `section`, `article`, `footer` 등 의미에 맞는 요소를 사용합니다.
- 페이지에서 가장 중요한 이름 또는 소개를 하나의 `h1`로 작성합니다.
- 각 주요 영역에 고유한 `id`를 지정해 내비게이션과 연결합니다.
- 버튼은 동작에, 링크는 페이지 이동에 사용합니다.
- CSS는 `css/style.css`, JavaScript는 `js/main.js`에서 불러옵니다.
- JavaScript 파일은 `defer` 속성으로 로드합니다.

권장 섹션 ID는 다음과 같습니다.

```text
#home
#about
#skills
#projects
#contact
```

## 4. CSS 작성 기준

- 색상, 글꼴, 간격은 `:root`의 CSS 사용자 정의 속성으로 관리합니다.
- 모바일 화면을 기본으로 작성한 뒤 미디어 쿼리로 넓은 화면을 확장합니다.
- 전체 콘텐츠의 최대 너비를 정하고 화면 중앙에 배치합니다.
- 반복되는 버튼, 카드, 제목 스타일은 공통 클래스로 만듭니다.
- 클래스 이름은 역할을 알 수 있도록 일관되게 작성합니다.
- 애니메이션은 짧고 절제되게 사용하며 `prefers-reduced-motion`을 지원합니다.

예시 디자인 토큰:

```css
:root {
  --color-primary: #2563eb;
  --color-text: #111827;
  --color-muted: #6b7280;
  --color-background: #ffffff;
  --color-surface: #f3f4f6;
  --content-width: 1120px;
  --radius: 12px;
}
```

## 5. JavaScript 작성 기준

- DOM이 준비된 뒤 필요한 요소를 찾거나 `defer`로 스크립트를 로드합니다.
- 요소가 존재하는지 확인한 후 이벤트를 등록합니다.
- HTML에 직접 `onclick`을 작성하지 않고 `addEventListener`를 사용합니다.
- 상태에 따라 `aria-expanded`, `aria-current` 등의 접근성 속성을 갱신합니다.
- 테마 선택을 저장한다면 `localStorage`를 사용하되 시스템 테마를 기본값으로 존중합니다.
- 전역 변수를 최소화하고 기능별로 작은 함수로 나눕니다.

## 6. 작업 순서

1. 프로필에 사용할 콘텐츠와 이미지를 준비합니다.
2. `index.html`에 모든 섹션의 의미 있는 구조를 작성합니다.
3. `style.css`에 공통 스타일과 모바일 레이아웃을 작성합니다.
4. 태블릿과 데스크톱 미디어 쿼리를 추가합니다.
5. `main.js`에 모바일 메뉴와 필요한 상호작용을 구현합니다.
6. 실제 콘텐츠, 이미지와 링크를 적용합니다.
7. 여러 화면 크기와 브라우저에서 확인합니다.
8. 접근성, 링크, 콘솔 오류 및 성능을 점검합니다.

## 7. 로컬 실행 방법

간단한 확인은 `frontend/index.html`을 브라우저에서 직접 열어 진행할 수 있습니다. 모듈 사용이나 브라우저 보안 정책으로 문제가 생기면 `frontend` 폴더에서 로컬 개발 서버를 실행합니다.

예시:

```powershell
cd frontend
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 8. 테스트 체크리스트

- [ ] 320px 화면에서 가로 스크롤이 생기지 않는다.
- [ ] 모바일 메뉴를 키보드와 포인터로 열고 닫을 수 있다.
- [ ] 내비게이션 링크가 정확한 섹션으로 이동한다.
- [ ] 프로젝트 링크가 새 탭에서 안전하게 열린다.
- [ ] 이미지 로딩 실패 시에도 내용을 이해할 수 있다.
- [ ] 다크 테마를 넣었다면 새로고침 후 설정이 유지된다.
- [ ] JavaScript가 꺼져도 핵심 콘텐츠를 읽을 수 있다.
- [ ] 개발자 도구 콘솔에 오류가 없다.
