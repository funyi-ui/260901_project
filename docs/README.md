# 개인 프로필 페이지 문서

이 폴더는 HTML, CSS, JavaScript로 제작하는 개인 프로필 페이지의 기획과 구현 기준을 관리합니다.

## 문서 목록

- [요구사항](./requirements.md): 페이지 목적, 대상 사용자, 화면 구성, 기능 및 품질 기준
- [구현 가이드](./implementation-guide.md): 권장 파일 구조, HTML/CSS/JavaScript 작성 방식, 작업 순서

## 프로젝트 목표

개인의 소개, 기술, 프로젝트, 연락처를 한 화면에서 명확하게 전달하는 반응형 웹 페이지를 만듭니다.

## 권장 결과물

```text
frontend/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    └── icons/
```

백엔드 없이 브라우저에서 바로 실행할 수 있는 정적 웹 페이지를 기본 범위로 합니다.
